# The Odin Project - Estudos

Este repositório centraliza todos os materiais e projetos desenvolvidos durante meus estudos na trilha do [The Odin Project](https://www.theodinproject.com/). Aqui você encontrará exercícios, projetos práticos e implementações que demonstram o progresso no aprendizado de desenvolvimento web.

## Sobre o The Odin Project

O The Odin Project é uma trilha de estudos gratuita e open-source para desenvolvimento web full-stack, cobrindo desde os fundamentos do HTML/CSS até frameworks avançados como React e Node.js.

## Estrutura do Repositório

### 🎨 Intermediate HTML and CSS

Projetos desenvolvidos na seção [**Intermediate HTML and CSS**](https://www.theodinproject.com/paths/full-stack-javascript/courses/intermediate-html-and-css), focados em conceitos Intermediários de HTML e CSS:

#### 📅 Projetos (por ordem de desenvolvimento)

- **[Sign-up Form](https://github.com/ChristoferLv/top-sign-up-form)** - Formulário de cadastro básico explorando conceitos de HTML Forms e estilização de formulários com CSS.


### 🎯 Foundations

Projetos desenvolvidos na seção [**Foundations**](https://www.theodinproject.com/paths/foundations/courses/foundations), focados nos fundamentos de HTML, CSS e JavaScript básico:

#### 📅 Projetos (por ordem de desenvolvimento)

- **[Calculadora](https://github.com/ChristoferLv/top-calculator)** - Calculadora funcional com interface gráfica. Treino de lógica JavaScript e operações matemáticas.

- **[Etch-a-Sketch](https://github.com/ChristoferLv/top-etch-a-sketch)** - Aplicação interativa para desenhar em uma grade, simulando o brinquedo clássico. Foco em manipulação do DOM e eventos JavaScript.

- **[Pedra, Papel e Tesoura](https://github.com/ChristoferLv/top-rock-paper-scissors)** - Jogo clássico contra o computador. Introdução à lógica de programação e estruturas condicionais.

- **[Landing Page](https://github.com/ChristoferLv/top-landing-page)** - Página de apresentação moderna. Prática de layout com CSS Flexbox.

- **[Odin Recipes (com CSS)](Foundations/odin-recipes-css/)** - Versão estilizada do site de receitas. Aplicação de estilos CSS para melhorar a apresentação.

- **[Odin Recipes](Foundations/odin-recipes/)** - Site básico de receitas usando apenas HTML. Primeiro projeto para treinar estrutura HTML semântica.
